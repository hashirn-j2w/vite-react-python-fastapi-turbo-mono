# vite-react-python-fastapi-turbo-mono

Turborepo + pnpm monorepo: a React 19 / Vite frontend and a FastAPI backend (uv),
connected by a TypeScript client generated from the API's OpenAPI schema.

| Path                         | What                                                                             |
| ---------------------------- | -------------------------------------------------------------------------------- |
| `apps/web`                   | React 19, Vite 8, Tailwind CSS v4, TanStack Query                                |
| `apps/api`                   | FastAPI + Pydantic, uv workspace member `api`                                    |
| `packages/ui`                | shadcn/ui components (Base UI variant, `base-nova` style)                        |
| `packages/api-client`        | Generated by `@hey-api/openapi-ts`: fetch SDK, types, Zod schemas, Query options |
| `packages/typescript-config` | Shared `tsconfig` presets                                                        |

## Setup

Requires Node ≥ 20, pnpm and [uv](https://docs.astral.sh/uv/) on `PATH`.

```bash
pnpm install
```

```bash
uv sync --all-packages
```

## Commands

| Command                  | Does                                                              |
| ------------------------ | ----------------------------------------------------------------- |
| `pnpm dev`               | Generates the client, runs FastAPI on :8000 and Vite on :5173     |
| `pnpm generate`          | FastAPI → `apps/api/openapi.json` → `packages/api-client/src/gen` |
| `pnpm build`             | Builds the web app (`apps/web/dist`) and the API wheel (`dist/`)  |
| `pnpm typecheck`         | `tsc` for TS packages + pyright for Python                        |
| `pnpm turbo quality`     | oxlint, `oxfmt --check`, `ruff check`, `ruff format --check`      |
| `pnpm turbo quality:fix` | Applies lint fixes, then formats (oxfmt + ruff)                   |

`pnpm lint` / `pnpm format` run only the Oxc tools (they're the root tasks from the
Turborepo Oxc guide); `turbo run quality` covers both languages.

## How the API client works

1. `api#generate` exports FastAPI's schema to `apps/api/openapi.json`.
2. `@workspace/api-client#generate` runs `openapi-ts` on it.
3. `build`, `typecheck` and `dev` depend on `^generate`, so Turborepo regenerates
   (or restores from cache) before anything consumes the client. Generated files are
   gitignored.

Operation IDs are the route function names (`list_items` → `listItems`,
`listItemsOptions`, `createItemMutation`, `zItemCreate`), so keep them unique.
While `pnpm dev` is running, run `pnpm generate` after changing API models.

```tsx
import { useQuery } from "@tanstack/react-query"
import { listItemsOptions } from "@workspace/api-client/query"

const items = useQuery(listItemsOptions({ query: { q: "desk" } }))
```

In dev, Vite proxies `/api` to FastAPI, so the client calls the same origin. Set
`VITE_API_URL` when the API is served from another origin, and `API_CORS_ORIGINS`
(JSON list) on the API.

## shadcn/ui

Components live in `packages/ui`. Add more from the repo root:

```bash
pnpm dlx shadcn@latest add dialog -c apps/web
```

## Python

The root `pyproject.toml` is a uv workspace; Turborepo discovers its members through
the experimental `futureFlags.experimentalPythonWorkspaces`. Ruff and pyright are
declared once at the root, so Turborepo maps `lint`/`format` to ruff and `check` to
pyright for every member. Add a member by creating its `pyproject.toml` and listing it
in `[tool.uv.workspace] members`.

## Notes

- TypeScript is pinned to 6.x (pnpm catalog): `@hey-api/openapi-ts` still needs the
  TypeScript compiler API, which the native TypeScript 7 doesn't ship.
- Shared dependency versions live in the `catalog` in `pnpm-workspace.yaml`.
- oxlint also runs the vendored [anti-slop](tools/oxlint/anti-slop/UPSTREAM.md) plugin
  (all rules at `error`). Update it with the `install-anti-slop` skill, not by
  replacing the directory.
